# ApplicantsTools Mini App

Статический сайт для Telegram Mini App. Публикация на GitHub Pages; сервер,
платный хостинг и постоянно запущенный процесс не нужны.

При добавлении партии дубли проверяются только среди контактов на текущем складе
и внутри добавляемого списка. История выдач в проверке не участвует: ранее
выданный контакт можно добавить снова, если его сейчас нет на складе.

## Подключение бота позже

1. Создайте бота через @BotFather.
2. `/mybots` → выберите бота → Bot Settings → Menu Button → Configure menu button.
3. Укажите HTTPS-ссылку сайта и название кнопки «Открыть склад».
4. При желании настройте Main Mini App в Bot Settings → Configure Mini App.
5. Откройте приложение из бота. Статус сверху должен показывать «Облако Telegram».

Токен бота не нужен в коде сайта. Не добавляйте его в репозиторий или URL.
Без серверной части бот служит точкой входа в Mini App; команды в чате
не обрабатываются. Все операции выполняются через интерфейс Mini App.

## Где данные

В обычном браузере: localStorage этого браузера. В Mini App: Telegram CloudStorage,
отдельно для каждого пользователя и бота, с синхронизацией между его устройствами.
Это личный склад, не общая база сотрудников. Сайт не отправляет контакты на GitHub.
В репозиторий входят только код и интерфейс.

Первый импорт: скачайте/выберите `sklad.json` из ApplicantsTools и нажмите «Импорт .json».
Данные из браузера не переносятся в Telegram автоматически: экспортируйте JSON
в браузере и импортируйте его внутри Mini App. Исходное приложение не изменяется.

Облако Telegram поддерживает 1024 ключа по 4096 символов. В приложении снимок
разбит на части по 3000 символов, до 250 частей на снимок. Следующая версия
записывается до смены указателя, а загрузка проверяет SHA-256. Ошибка записи
не изменяет видимый склад; предыдущий снимок остаётся доступным. Старые
незавершённые поколения удаляются перед очередным сохранением.

При работе с нескольких устройств обновляйте склад перед изменениями и не
редактируйте его одновременно: Telegram CloudStorage не предоставляет
атомарную compare-and-swap транзакцию между устройствами. Приложение обнаруживает
изменение версии перед сохранением, но не может гарантировать разрешение
двух строго одновременных записей. Регулярно скачивайте резервные копии.

Сортировка и её черновик выполняются локально. Текст сортировки хранится в текущей
сессии браузера; в облако попадают только контакты, которые вы добавили на склад.

Документация: https://core.telegram.org/bots/webapps#cloudstorage

## Публикация

GitHub repository → Settings → Pages → Deploy from a branch → main → /(root).
В GitHub Free исходники сайта должны быть в публичном репозитории. Данные
пользователей и токены не должны попадать в репозиторий.

## Локальная проверка

```sh
python3 -m http.server 8080
node --test test.mjs
```

Затем откройте http://localhost:8080. Проверки используют вымышленные контакты.
Живой Telegram CloudStorage можно проверить после создания бота и подключения
Mini App; до этого тестируется адаптер с подменой Telegram API.
